# Images — drop your real photos here

The site works right now with labelled placeholders. To replace a placeholder with
a real photo, just add a file with the **exact name** below into this folder (or the
matching sub-folder). No code changes needed — refresh the page and it appears.

Use JPG (photos) or SVG (logo/map). Compress before uploading (e.g. squoosh.app) so
pages stay fast. Suggested minimum sizes are shown.
